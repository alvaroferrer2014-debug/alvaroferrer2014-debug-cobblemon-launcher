# Servidor LaucherCobblemon

Servidor dedicado para **Minecraft 1.21.1 + Fabric + Cobblemon 1.7.3**.

## Requisitos
- Java 21 o superior.
- Una máquina/PC donde ejecutar el servidor.
- Puerto TCP `25565` si quieres que sea accesible desde Internet.

## Preparación
1. Descarga el Fabric Server Launcher para Minecraft 1.21.1 desde la web oficial de Fabric.
2. Ejecuta el instalador/launcher con Java 21.
3. Coloca en `mods/` las mismas versiones de **Fabric API** y **Cobblemon** que usa el launcher.
4. Acepta el EULA creando `eula.txt` con `eula=true`.
5. Arranca el servidor con Java 21.

## Configuración recomendada
El servidor debe usar el mismo Minecraft, Fabric Loader, Fabric API y Cobblemon que el cliente para evitar incompatibilidades.

Los archivos de mundo y la configuración del servidor deben permanecer fuera del repositorio para no subir datos pesados o privados a GitHub.
