# LaucherCobblemon

Launcher para **Cobblemon en Fabric 1.21.1**.

## Objetivo
Crear un launcher de escritorio que prepare y ejecute Minecraft 1.21.1 con Fabric y Cobblemon de forma sencilla.

## Funciones previstas
- Interfaz gráfica sencilla.
- Preparación de Fabric 1.21.1.
- Instalación y comprobación de Cobblemon y dependencias.
- Gestión de la carpeta del juego.
- Configuración de memoria RAM.
- Botón para iniciar el juego.
- Comprobación de archivos antes de iniciar.

## Estado
Proyecto inicial.
